# WashNgo 5-Minute Standup Script

**Facilitator:** Rotate | **Timer:** On screen

### 0:00-0:30 Opening — Facilitator
> "WashNgo 5-min — Pick Up. Clean. Deliver. Easy. Updates only, no solving. Go."

### 0:30-3:00 Updates (45s each)
**Customer:** "Done: [e.g., booking filters + proof preview]. Next: [distance sort]."
**Rider:** "Done: [online + photo proof + pagination]. Next: [push]."
**Laundry:** "Done: [accept/reject polish]. Next: [hours]."
**Admin/Infra:** "Done: [metrics|suspend]. Next: [push creds]."

*No demo — link video in Slack.*

### 3:00-4:00 Blockers (15s each)
> "Blocker + need + by when — else offline after."
> e.g., "Need APNs key Carl by Thu — blocked push."

No discussion — park it.

### 4:00-5:00 Commit & Close — PM
> "Top 1 commit each: Customer [X], Rider [Y], Laundry [Z]. Done by Fri 5pm, typecheck+lint green. Post update sa #washngo-updates. Done — thanks!"

**Rules:** Timer strict, 1 blocker rule, no laptops. Absent = post async:
`Done: - | Blocker: - | Next: -`
